* Alleles are different versions of gene that code for same trait
* Different genotypes code for different phenotypes

* Primary structure
    * Chain of amino acids
    * Uses peptide bonds
* Secondary structure
    * Alpha helices or beta pleated sheets
    * Uses hydrogen bonds
* Tertiary structure
    * Ionic bonds between positive and negative amino acids
    * Covalent bonds between cysteine amino acids
    * LDFs repelling hydrophobic amino acids
* Quaternary structure
    * Multiple folded chains held together by IMFs
    * Same interaction types as tertiary structure
