* Uses deoxyribose instead of ribose
    * Lacks extra O on 2' carbon
* More expensive to create than RNA
    * DNA uses thymine instead of uracil
        * Cytosine can degrade into uracil, more likely over longer time
        * DNA can remove all uracil, since it only uses thymine
* DNA can compact to varying degrees
    * Used to store DNA in a tiny nucleus
    * Most condensed form forms a chromosome
* For mitosis, copy all DNA and split to two cells
    * Requires fully condensed DNA
* Is transcribed into RNA
    * [Transcription](rna-transcription) happens in nucleus
    * Matching bases link to create RNA strand
    * Can have multiple genes to create different RNA
        * Genes have regulatory and coding regions
* Cells in the body contain DNA
    * All DNA in the body came from one original copy
    * [Replicated](dna-replication) during cell cycle
