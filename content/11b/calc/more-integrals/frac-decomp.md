# partial fraction decomposition

$\int \frac{x - 1}{x^2 - 4} dx$

$\frac{x - 3}{x^2 - 4}$
$= \frac{x - 3}{(x + 2)(x - 2)}$
$= \frac{A}{x + 2} + \frac{B}{x - 2}$
$= \frac{A(x - 2) + B(x + 2)}{(x + 2)(x - 2)}$
$= \frac{x(A + B) + (-2A + 2B)}{(x + 2)(x - 2)}$

$x(A + B) + (-2A + 2B) = x - 3$

$A + B = 1$
$-2A + 2B = -3$

$A = \frac{5}{4}$
$B = -\frac{1}{4}$

$= \frac{1}{4}(\frac{5}{x + 2} - \frac{1}{x - 2})$
$\frac{1}{4} \int \frac{5}{x + 2} - \frac{1}{x - 2} dx$
